# Contributing to Oathbound

## Documentation workflow

1. Create a focused branch.
2. Follow `docs/_meta/UPDATE_PROTOCOL.md`.
3. Update authoritative files before dependent summaries.
4. Preserve document IDs and status metadata.
5. Add major approved changes to the decision log.
6. Open a pull request describing scope, affected systems, and unresolved questions.

## Commit guidance

Use concise imperative messages, for example:
- `Update Returning Blood canon`
- `Add Area 2 enemy documentation`
- `Revise Milestone 2 dependency order`

Avoid combining unrelated lore, gameplay, and production changes in one commit when they can be reviewed separately.
