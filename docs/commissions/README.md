# Character Commission Documents

This section owns artist-facing commission briefs for external character production. These files translate Oathbound's gameplay and presentation requirements into practical deliverables without making the commissioned art authoritative for combat rules.

## Akio

- `akio/AKIO_COMMISSION_MASTER_BRIEF.md` — character goal, visual identity, Blood Aspect compatibility, scope and non-goals.
- `akio/AKIO_ANIMATION_SCOPE.md` — staged animation request for the first commission and later expansions.
- `akio/AKIO_TECHNICAL_DELIVERABLES.md` — source-file, rig, rendering, eight-direction and rights requirements.
- `akio/AKIO_COMMISSION_MILESTONES.md` — recommended approval/payment milestones and acceptance gates.

## Production rule

Commission briefs describe the intended *feel* and role of animations, not hard combat timestamps. The animator should have room to design convincing anticipation, impact and recovery. Godot remains authoritative for gameplay timing, movement, hitboxes, damage and cancel windows, and those values may be tuned around accepted animation after delivery.

The first Akio commission is no longer treated as disposable prototype art. It should be built as a plausible baseline for final Akio production, while keeping the first animation package deliberately narrow enough to validate the asset and the 3D-rig-to-2D pipeline before expanding into Blood Aspect-specific libraries.
