## Goal

Create the persistent hub, recurring NPC cast, physical progression stations, training spaces, revival presentation, and meta-system interface language.

## Planned scope

- Keeper, Peddler, Smith, Raven, Undead Samurai, and Scribe
- Strand docks, paths, stations, and environmental kit
- Boat
- Forge Bench with distinct Prosthetic and Relic progression/management presentation
- Discovery Board, including scalable Technique records
- Bloodwell and reformation presentation, with Akio and Run Infrastructure progression categories
- Blood Cavern outer training hall
- Blood Mirror inner chamber with a clear opening locked state and later unlocked Aspect progression/trial state
- Merchant, Forge, Discovery, Bloodwell, Mirror/trial, run-results, and pause/overview UI
- Trial-state, temporary-loadout preview, completion, reward, Technique-pool unlock, and mastery presentation

No separate Relic Reliquary station or generic weapon-development / weapon-socket Forge tree is included.

The full in-run Technique reward, replacement, Supporting/Cross-family/Legendary, and refinement interface remains Milestone 4 scope. Milestone 3 only needs the trial and codex states required by the Strand.

## Approved permanent progression station scope

- **Bloodwell:** Akio + Run Infrastructure.
- **Forge Bench:** Prosthetics + Relics.
- **Blood Mirror:** Blood Aspects after later campaign/onboarding unlock.

Exact node counts, values, mastery thresholds, costs, and unlock timing remain later detailed design and do not block high-level Strand production planning.

## Dependency rules

- NPC service and progression behavior must be documented before final interface art.
- Blood Mirror UI inherits the Blood Aspect, Technique trial, reward, and later-unlock boundaries established in gameplay documentation.
- Trial screens require fixed Aspect, Technique, Prosthetic, or Relic loadout, completion, reward, and mastery data before final layout.
- Technique trial loadouts must read as temporary and clear when the trial ends.
- Bloodwell return effects follow finalized persistence and successful-return rules.
- Bloodwell interface art must support Akio + Run Infrastructure without inventing final node branches.
- Forge interface art must support Prosthetic + Relic categories without reviving generic weapon development.
- Physical stations and primary landmarks are approved before final hub layout and lighting.
- Hub navigation must be tested through repeated return loops, not only as a single establishing scene.
- Individual NPC and station files own detailed requirements; this milestone owns their production grouping.

## Completion test

All six NPCs and major services can be located, distinguished, interacted with, and understood without visual confusion. Training, later-unlocked Aspect progression/trials, Technique demonstrations, permanent progression, revival, results, and repeated departure all work as one coherent hub loop.
