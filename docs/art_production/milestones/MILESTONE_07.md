# Milestone 7 — Release Presentation and Cohesion

## Goal

Complete global presentation, remaining external-facing art, missing assets, and cross-game visual consistency after all major systems and regions exist.

## Planned scope

- Title, logo, main menu, Continue/New Game, settings, controls, loading, save, pause, credits, and completion screens
- Dialogue frames, portraits or narrative stills if retained
- Boss title cards and run-results polish
- Achievement icons
- Application icon
- Store capsule, key art, and trailer cards
- Accessibility and input-state visual pass
- Missing-asset audit
- Cross-area scale, palette, shadow, VFX, UI, and performance review
- Source-file organization and final export cleanup

## Boundary

This milestone is not a place to hide unfinished regions, bosses, or core gameplay systems. Large missing content must return to its authoritative milestone or receive a newly approved scope change.

## Completion test

The game presents one coherent visual product from startup through completion, all required release assets exist, no major placeholder art remains, and the source/export structure is suitable for maintenance and shipping.
