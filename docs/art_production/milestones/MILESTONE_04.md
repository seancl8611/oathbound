# Milestone 4 — Player Combat Depth

## Goal
Complete production presentation for Akio's three Blood Aspects and the run-build systems after the base character/source-rig pipeline is proven.

## Scope

- Wolf, Wraith, and Ronin Tier 0-IV presentation families.
- Tier II Blood buildup/readiness and the three Blood Arts.
- Eight Prosthetic VFX/icon families.
- Technique reward/build presentation for the current **40 Techniques + 6 refinements**.
- Technique family language for Echo, Rupture, Seal, Rift, and Crimson.
- Relic card/icon support and run HUD integration.

## Technique presentation

Technique ownership is **unlimited additive ownership** for the run. Trigger labels are **trigger labels, not equipment slots**.

Current global Action Technique triggers are:

- Basic Attack;
- Held Attack;
- Dash / Dash Attack.

Kit-specific events may receive explicitly restricted hooks. Do not build universal Parry/Counter or Deathblow/execution Technique presentation back into the global system.

## Aspect presentation

- **Wolf:** fast close pressure, player-directed pursuit, connected aggression.
- **Wraith:** longer spectral reach, spacing, frontal geometry/control.
- **Ronin:** slow heavy commitment, strongest Guard identity, Reprisal, deliberate impact.

Ronin's current repeated defensive growth is blocked-Health efficiency, not a player Posture-capacity meter. No universal Posture/deathblow presentation is part of this milestone.

## Production order

1. Approve base Akio source-rig and directional render treatment.
2. Establish reusable Aspect overlays/material/weapon/VFX language.
3. Prototype one representative Tier progression per Aspect at gameplay scale.
4. Complete Blood states/Blood Arts.
5. Complete Prosthetic and Technique presentation using reuse-first rules.
6. Validate mixed-build readability in real encounters before bespoke polish expands.

## Completion test

The three Aspects remain distinguishable at the accepted high-angle camera; Blood/Tier/Technique effects remain readable without obscuring threats; Technique UI never implies slots or overwriting; and no production asset depends on retired universal Posture, Deathblow/execution, or universal-counter assumptions.
