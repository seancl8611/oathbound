## Milestone rule

A milestone defines:

- Meaningful completion and playtest goal
- Dependencies inherited from earlier work
- Included and deferred scope
- Internal production order
- Review gates
- Completion test

The contractor-facing Word/PDF version may include payment, ownership, signatures, and detailed animation tables. The Markdown file remains the internal scope authority.
