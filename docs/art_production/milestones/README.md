# Art Production Milestones

Each top-level art milestone receives its own Markdown source document. Milestones are production and playtest groupings, not equal-size contracts.

Planned files:
- `MILESTONE_01.md`
- `MILESTONE_02.md`
- `MILESTONE_03.md`

- `MILESTONE_05.md`
- `MILESTONE_06.md`
- `MILESTONE_07.md`

Each milestone should define dependencies, included assets, internal batches, review gates, deferred scope, and links to authoritative gameplay/content files.
