# Hub Interfaces

The Strand's interfaces should feel like services embodied in physical stations, not disconnected menu screens.

## Planned interfaces

- Boat / run departure
- Merchant
- Forge
- Discovery Board / codex
- Bloodwell progression
- Blood Mirror / Blood Aspect selection and trials
- Run results
- Pause / character overview

## Shared requirements

- Reuse typography, frames, icon logic, and input states across services.
- Keep the station and NPC visible where useful so the interface remains grounded in the world.
- Clearly separate permanent upgrades, run-only choices, discoveries, and currencies.
- Show locked requirements without revealing unintended spoilers.
- Support controller and keyboard navigation.
- Avoid designing final layouts before the underlying progression structure and data fields are documented.

## Dependency map

- Boat depends on run structure and available destinations.
- Forge depends on permanent equipment/prosthetic progression.
- Discovery Board depends on codex categories and unlock rules.
- Bloodwell depends on persistent Returning Blood progression.
- Blood Mirror depends on Blood Aspects and trial structure.
