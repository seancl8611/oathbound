# Oathbound Terminology

Use these terms as canonical search anchors. Prefer the exact capitalization and wording below in authoritative documentation.

## World, story, and campaign

| Preferred term | Definition / usage |
|---|---|
| **Oathbound** | Current project title. |
| **Beast Blood** | Corrupting supernatural power obtained deliberately from the Heart. |
| **the Heart** | Ancient living godlike organ / supernatural core that produces Beast Blood. Ultimate origin remains deliberately ambiguous. |
| **ancient Heart complex** | Pre-Shogun structure around the imprisoned Heart. Not a proper name. |
| **Heart Binding** | One of seven ancient restraints. The Court destroyed one before the game; Akio destroys the remaining six. |
| **extraction apparatus** | Court-built mechanism placed against the exposed Heart after the historical Binding breach. |
| **forbidden extraction** | Offering fresh human blood through the apparatus and collecting Beast Blood released by the Heart. |
| **Returning Blood** | Akio's inherited Beast Blood expression that reconstructs his established human form after death. |
| **true control** | Akio's unique ability to preserve agency, Resist escalation, vary Aspect expression, and oppose the Heart. |
| **Blood Moon** | Recurring Heart cycle that strengthens existing Beast Blood and pressures the barrier. |
| **Heart Binding ritual** | Successful-run sequence: Returning Blood offering, one Binding breaks, Heart dissolves Akio, Akio reconstructs at the Strand. |

## Regions and major encounters

| Preferred term | Definition / usage |
|---|---|
| **Hushiro Gate Village** | Area 1; theme: rupture. |
| **Yomori Grove** | Area 2; theme: adaptation. |
| **Kagutsuchi Court** | Area 3; theme: false ascendancy. |
| **rupture** | Hushiro's regional theme: recent collapse, violence, bodily instability, fragmented community. |
| **adaptation** | Yomori's regional theme: long-term predation/spirit persistence/ecological damage caused by corrupted inhabitants; not environmental transmission. |
| **false ascendancy** | Kagutsuchi's belief that disciplined mutation equals mastery despite continued inability to reject Beast Blood. |
| **Keeper of the Gate** | Area 1 regional boss. Use the full name when the Strand Keeper could be confused. |
| **Twin Maws** | Area 2 paired regional boss: Rootfang and Briarthorn. |
| **Rootfang / Briarthorn** | Twin Maws combatants; the first defeated empowers the survivor. |
| **Blood Lotus** | Area 3 miniboss. |
| **Eternal Swordsman** | Area 3 miniboss. |
| **Eclipse Shogun** | Area 3 regional boss and central character antagonist. He is not the Heart. |
| **Spillborn** | Weak expendable unit spawned by a Hollow Vessel. |

## Run build and combat

| Preferred term | Definition / usage |
|---|---|
| **Blood Aspect** | Controlled Returning Blood specialization and the run's weapon-kit identity. |
| **Wolf / Wraith / Ronin** | Current launch Blood Aspects. |
| **Tier 0 / Tier I–IV** | Blood Aspect progression labels. |
| **Corruption** | Run-only Shrine-ready pressure meter. Not currency, morality, or Blood Art charge. |
| **Resist** | Shrine choice that stabilizes Corruption without advancing Tier. |
| **Embrace** | Shrine choice that advances the active Aspect one Tier. |
| **Technique** | Temporary run upgrade tied to one of five sword actions or the slotless supporting layer. |
| **slotted Technique** | Direct Technique occupying Basic Attack, Held Attack, Dash, Parry / Counter, or Deathblow. |
| **Supporting Technique** | Slotless same-family Technique. |
| **Cross-family Technique** | Slotless hybrid Technique requiring investment in two Technique families. |
| **Legendary Technique** | Family capstone requiring approved native-family investment and any entry-specific prerequisite. |
| **refinement** | One small improvement to an eligible slotted Technique; maximum one per parent Technique. |
| **replacement** | Rare offer that overwrites the current direct Technique in the same combat slot. |
| **Echo** | Delayed additional sword slashes. |
| **Rupture** | Enemy buildup meter; completion triggers major posture impact plus bounded nearby posture pressure. |
| **Seal** | Visible marks progressively restrict movement; three briefly Bind the target. |
| **Rift** | Visible fracture mark that opens after a short fuse for direct Health damage and can intensify before opening. |
| **backstab** | Universal positional hit classification for a valid sword hit genuinely delivered from the enemy's rear region. |
| **Vulnerable** | Crimson status that substantially increases genuine backstab Health damage. It does not slow, stun, root, alter facing, or change awareness. |
| **Unseen** | Crimson Legendary using brief invisibility / awareness suppression under the Technique authority. |
| **combat verb** | Shared action concept such as parry, posture, deathblow, dash, backstab, movement, or Spirit. |

## Persistent systems and locations

| Preferred term | Definition / usage |
|---|---|
| **The Strand** | Persistent shoreline hub and controlled barrier threshold. |
| **Bloodwell** | Permanent progression station for Akio + Run Infrastructure. One word. |
| **Run Infrastructure** | Bloodwell-owned umbrella for future-run support: Rest, Shrine, reward, routing, transition, and related expedition support. |
| **Forge Bench** | Permanent progression/management station for Prosthetics + Relics. |
| **Blood Cavern** | Training/trial space containing the Blood Mirror. |
| **Blood Mirror** | Later-unlocked permanent Blood Aspect progression station inside the Blood Cavern. |
| **Relic** | Persistent collectible with one equipped slot, a run-active benefit, and individual persistent mastery/progression. |
| **Relic mastery** | Persistent progress earned by the equipped Relic from eligible kills. Not currency. |

## Prosthetics

Current names: **Beast-Bane Whistle, Thunder Rod, Smoke Gourd, Fang Harpoon, Mirror Umbrella, Flame Vent, Mist Raven, Bloodletting Gourd**.

`Burn` belongs to Flame Vent / explicitly documented mechanics. `Shock` belongs to Thunder Rod / explicitly documented mechanics.

## Resources

| Preferred term | Definition / usage |
|---|---|
| **Mist** | Broad persistent meta currency. |
| **Scroll / Scrolls** | Persistent Forge-focused currency primarily used for Prosthetic development. |
| **regional boss material** | Boss-specific low-count permanent upgrade material. One unique material exists for Keeper of the Gate, Twin Maws, and Eclipse Shogun. Exact player-facing item names are not yet locked. Search aliases: `boss material`, `boss drop`, `boss resource`. |
| **Gold** | Run-only Shop currency. |

There is **no generic Boss Emblem currency** in current design.

Regional boss materials are not general currencies: each boss drops exactly one of its own material per kill, and the material is used sparingly as a secondary requirement on selected major permanent upgrades.

## UI / rarity conventions

- **Common / Uncommon / Rare / Legendary** are Technique rarity tiers.
- Relics do not use rarity tiers.
- `posture` and `deathblow` are lowercase in prose unless used as official UI labels.

# Deprecated, superseded, or rejected wording

Use this section when searching for stale references.

- `Boss Emblem / Boss Emblems` — removed; use regional boss materials where a boss-specific low-count upgrade gate is intended.
- `Mist Shards` — deprecated.
- `Mistveil` — removed from current lore.
- `boon` — use `Technique` for ordinary run upgrades.
- `active Technique`, `reserve Technique`, four-active-plus-reserve loadout, routine Rest-room Technique swapping — superseded by five direct slots plus slotless Techniques.
- `Prosthetic Technique` — removed; Prosthetic progression belongs to Forge permanent progression.
- Crimson `Burst`, Burst-ready targets, Burst recharge, close-range Burst recovery — superseded by Vulnerable / backstab / direct Health damage.
- Widened rear arc, forced facing, or ordinary slow as Crimson's backstab-enabling mechanic — rejected.
- Old alternate-weapon development / weapon-socket Forge system — superseded by Blood Aspects.
- Old Bloodwell `Way of Steel / Way of Secrets / Way of Vows` structure — superseded by Akio + Run Infrastructure.
- Dedicated Relic Reliquary — removed; Relic management/progression belongs to Forge Bench.
- Storm, Frost, Ember, Hex, Shadow as player stance families — removed.
- Frost and Hex as baseline player status families — removed.
- `Wellspring` as a world location/system/extraction term — not approved.
- Eclipse Palace / underground city / living citadel as replacements for Kagutsuchi Court — rejected.

# Canon boundaries

Do not introduce the following through casual wording:

- Beast Blood is not airborne, bite-transmitted, or environmentally contagious.
- Returning Blood is not standard Order practice.
- The Order does not normally dose warriors with Beast Blood.
- Akio is not immune to Beast Blood.
- The Eclipse Shogun is not an Order founder/member and is not an innocent puppet.
- Other deliberate Beast Blood users do not possess true control equal to Akio.
- The Heart's cosmic origin and final anatomy remain deliberately unexplained.
- Working boss phase names and detailed attack lists are not canon until their encounter authority approves them.
