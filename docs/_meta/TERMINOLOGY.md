# Oathbound Terminology

Use this file to keep names, capitalization, and definitions consistent across the repository.

| Preferred term | Definition / usage |
|---|---|
| Beast Blood | The corrupting supernatural force affecting the island. Capitalize both words. |
| Returning Blood | Beast Blood transformed into obedience after submitting to Akio's resolve. |
| Blood Aspect | A controlled Returning Blood specialization. |
| Tier 0, Tier I, Tier II, Tier III, Tier IV | Standard progression labels for Blood Aspect mutation. |
| The Order | Akio's religious-military organization. |
| The Strand | The hub area. |
| Hushiro Gate Village | Area 1 region name. |
| Keeper of the Gate | Area 1 major boss name. |
| Eclipse Shogun | Final boss title. |
