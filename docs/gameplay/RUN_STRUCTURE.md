# Run Structure

A run begins after preparation in the Strand and ends through death, completion, or another explicit return condition.

## Regional flow

The current intended progression is:

1. Hushiro Gate Village
2. Yomori Grove
3. Kagutsuchi Court
4. Wellspring/final confrontation

Exact branching, area order flexibility, room counts, and rerouting rules remain implementation and playtest questions.

## Room functions

The game uses recognizable room categories:

- Combat
- Shrine
- Rest
- Shop
- Treasure/reward
- Miniboss
- Boss approach and boss arena

Each function should read before interaction through environment composition, focal props, lighting, and UI treatment.

## Death and return

Akio's death does not reset the fiction. Returning Blood reconstructs him and returns him to the Strand. This supports the roguelite loop while remaining a real supernatural event in the story.

## Run growth

A run may change through:

- Blood Aspect and Tier choices
- Stances
- Prosthetic tools and resources
- Boons and relics
- Consumables
- Currencies and materials
- Boss or discovery rewards

## Reset boundary

Temporary run power should reset according to the finalized progression model. Permanent knowledge, selected upgrades, discoveries, unlocks, and narrative state may persist. The exact persistence matrix must be finalized in `PROGRESSION.md` before implementation is considered locked.
