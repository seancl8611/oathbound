# Prosthetic Tools

Akio carries ritualized combat tools operated through a shared generic prosthetic-use animation and tool-specific effects.

## Current production scope

Eight prosthetic VFX families are planned. The exact tool roster and mechanics should be documented here before final outsourcing briefs are locked.

## Tool definition template

Each prosthetic must define:

- Name and visual object
- Tactical role
- Activation timing
- Spirit emblem cost
- Projectile, impact, area, or persistent effects
- Interaction with posture, health, hazards, and enemy defenses
- Blood Aspect and stance synergies
- Upgrade path, if any
- Required world sprite, icon, VFX, and sound

## Design constraints

- Tools should solve specific combat problems rather than serve as generic damage buttons.
- Tool effects must remain quieter than parry, posture break, deathblow, and boss-phase signals.
- The generic Akio activation pose should support the full roster where possible.
- A tool requiring a unique full-body animation must be identified as an explicit scope increase.
